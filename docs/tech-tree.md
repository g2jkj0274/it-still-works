# 아이템 테크트리

**여섯 단이다.** 맨손에서 시작해 발사대에서 끝난다.
단마다 세계에서 할 수 있는 일이 하나씩 늘어난다 —
먹는다 → 판다 → **자동이 된다** → 재료를 만든다 → 짓는다 → 지킨다.

|  | 수 |
|---|---|
| 자원 | 9종 |
| 도구 | 8종 |
| 제작법 | 32개 |
| 만드는 자리 | 3곳 (손 · 화로 · 작업대) |
| 회로 부품 | **5종 — 그대로** |
| 감지기가 보는 것 | 8 |
| 작동기가 다루는 것 | 8 |
| 부품 설정 가짓수 | **46** |
| 지을 수 있는 장치 | 17 |

원본은 `docs/spec.md` §3.1 · §3.6 · §4.2 · §4.3 · §5 다. 어긋나면 스펙이 옳다.

> **아직 구현되지 않았다.** 지금 코드에 있는 것은 자원 3종과 제작법 9개다.
> 이 문서는 그것을 무엇으로 바꿀지 적은 설계다.

## 여섯 단 — 닿으면 무엇이 달라지는가

### 0단 · 맨손 — **먹고 버틴다**

| | |
|---|---|
| 캔다 | 나무 · 흙 · 모래 · 작물 |
| 만든다 | 판자 |
| **할 수 있게 된다** | 배를 채운다. 흙과 나무를 쌓아 벽을 세운다 |
| 아직 못 한다 | **돌을 캘 수 없다.** 아무것도 자동이 아니다 |

야생 작물 열넷이 첫날의 시계다. 다시 나지 않는다.
배는 4분에 비고 5분 40초에 쓰러지는데 첫 밤은 7분에 온다.

**관문 →** 판자 3으로 **나무 곡괭이**

### 1단 · 판자 — **손이 도구를 갖는다**

나무 하나가 판자 넷이 된다. 이 환율이 첫날 예산을 세운다.

**판자는 제작법 32개 가운데 21개에 든다.** 도구도 부품도 장치도 전부 판자를
거친다. 나무가 사실상 모든 것의 뿌리다.

**관문 →** 나무 곡괭이가 **돌**을 연다

### 2단 · 돌 — **땅속이 열린다**

| | |
|---|---|
| 캔다 | 돌 |
| 만든다 | 돌 곡괭이 · 돌 도끼 · 돌 삽 · 화로 · 문 · 궤짝 · 밭 |
| **할 수 있게 된다** | 파고 내려간다. 문을 달고, 넣어 둘 곳을 갖고, 밭을 놓는다 |
| 아직 못 한다 | **화로를 세울 수는 있지만 돌릴 수는 없다** |

화로가 여기서 만들어지는데 손으로는 돌아가지 않는다.
**이 한 칸이 회로를 만들 이유가 된다.**

**관문 →** 돌 곡괭이가 **광석 · 불씨돌**을 연다

### 3단 · 회로 — **세계가 스스로 움직인다**

| | |
|---|---|
| 캔다 | 광석 · 불씨돌 |
| 만든다 | 감지기 · 작동기 · 되풀이 · 상자 · 갈림길 · 등 |
| **할 수 있게 된다** | **자동문 · 자동 조명 · 자동 농장.** 사람이 없어도 도는 것이 처음 생긴다. 등을 들고 더 깊이 내려간다 |

스펙 §6 검증 순서 1번이 여기다 — *"조작감이 재밌는가."*
**사람이 직접 판정하는 자리이고, 부품을 늘리기 전에 여기부터 봐야 한다.**

**관문 →** **작동기가 화로를 때린다**

### 4단 · 화로 — **재료가 재료를 낳는다**

| | |
|---|---|
| 굽는다 | 쇳덩이 · 깊은쇳덩이 · 벽돌 · 유리 · 숯 · 구운 작물 |
| **할 수 있게 된다** | **처음으로 캐지 않고 얻는다.** 여태 손에 든 것은 전부 땅에서 나온 것이었다 |

- 구운 작물이 포만도를 8 채운다. 날것은 4다 — 밥걱정이 준다
- 숯이 불씨돌을 대신한다. 나무 둘에 하나, 손해 보는 환율이다.
  땅속에 안 가고도 조금은 돌게 하되 내려가는 편이 늘 낫게 두었다
- **회로 없이는 이 단을 지날 수 없다.** 트리 전체의 허리다

**관문 →** **쇳덩이**가 작업대를 연다

### 5단 · 작업대 — **회로가 손을 갖는다**

| | |
|---|---|
| 만든다 | 작업대 · 쇠 곡괭이 · 쇠 도끼 · 튼튼한 문 · 밀개 · 놓개 · 종 |
| **할 수 있게 된다** | **회로가 짓고 옮기고 알린다** |

3단의 회로는 문을 여닫고 밭을 거두는 데 그쳤다. 여기서 회로가 **블록을 밀고
놓는다.** 덫문 · 자동 다리 · 자동 벽 · 경보가 이 단에서 선다.
튼튼한 문으로 밤에 회로를 지킨다.

**관문 →** **쇠 곡괭이**가 깊은광 · 빛돌을 연다

### 6단 · 깊은 곳 — **밤이 스스로 지켜진다**

| | |
|---|---|
| 캔다 | 깊은광 · 빛돌 |
| 만든다 | 깊은쇳덩이 · 깊은쇠 곡괭이 · 밝은 등 · 발사대 |
| **할 수 있게 된다** | **자동 방어.** §5 의 다섯 장치가 모두 선다 |

사람이 자는 동안에도 섬이 밤을 넘긴다.
밝은 등으로 가장 깊은 곳까지 밝아진다.

### 임계 경로 — 열다섯 마디

```
나무 → 판자 → 나무 곡괭이 → 돌 → 돌 곡괭이 → 광석 → 작동기 → 회로
  → 화로 → 쇳덩이 → 작업대 → 쇠 곡괭이 → 깊은광 → 깊은쇳덩이 → 발사대
```

## 자원 아홉 — 무엇에 쓰는가

| 자원 | 어디에 | 캐는 도구 | 드는 곳 |
|---|---|---|---|
| 나무 | 지표의 나무 10그루 | 맨손 | **판자** · 숯 |
| 흙 | 지표에서 두 층 | 맨손 | 밭 · 메우기 |
| 모래 | 물가 | 맨손 | 유리 |
| 작물 | 야생 14곳 · 밭 | 맨손 | 먹는다 · 구운 작물 |
| 돌 | 흙 아래 전부 | 나무 곡괭이 | 돌 도구 3종 · 화로 · 벽돌 · **발사대 탄** |
| 광석 | 자원지 3곳 · z ≤ 6 | 돌 곡괭이 | 부품 5종 · 등 · 쇳덩이 |
| 불씨돌 | z ≤ 5 | 돌 곡괭이 | **굽는 것 여섯 전부** |
| 깊은광 | z ≤ 3 | 쇠 곡괭이 | 깊은쇳덩이 |
| 빛돌 | z ≤ 2 | 쇠 곡괭이 | 밝은 등 |

### 가운데를 지나는 것 둘

제작법 32개에서 재료가 몇 번 쓰이는지를 세면 줄기가 보인다.

| 재료 | 드는 제작법 |
|---|---|
| **판자** | **21** |
| 광석 | 7 |
| **쇳덩이** | **7** |
| 불씨돌 | 6 |
| 돌 | 5 |

- **판자**는 도구 · 부품 · 장치를 전부 거친다. 그래서 나무가 마르면 트리가 통째로
  선다. 섬에 나무가 30칸뿐이고 다시 나지 않는다는 것이 이 설계에서 가장 조이는 줄이다
- **쇳덩이**는 5단 전부의 뿌리다. 쇳덩이를 얻으려면 화로를 돌려야 하고, 화로를
  돌리려면 회로가 있어야 한다. **트리의 허리가 회로를 지나게 만든 것이 여기서 걸린다**

### 가장 좁은 줄기

모래 → 유리 → 밝은 등. 셋뿐이고 다른 데로 가지 않는다.
**모래는 밝은 등을 위해서만 존재한다.** 빛돌도 마찬가지다.

### 돌에 소비처가 생겼다

12817칸으로 가장 많이 나오는데 오래 쓸 곳이 없었다.
지금은 돌 도구 셋 · 화로 8 · 벽돌 · **발사대 탄**으로 나간다.
탄은 제작법이 아니라 쏠 때마다 하나씩 든다(§4.2).

## 도구 여덟 — 무엇을 캘 수 있는지를 가른다

| 도구 | 드는 것 | 캘 수 있는 것 |
|---|---|---|
| 맨손 | — | 나무 · 흙 · 모래 · 작물 |
| 나무 곡괭이 | 판자 3 | + 돌 |
| 돌 곡괭이 | 판자 2 + 돌 3 | + 광석 · 불씨돌 |
| 쇠 곡괭이 | 판자 2 + 쇳덩이 3 | + 깊은광 · 빛돌 |
| 깊은쇠 곡괭이 | 판자 2 + 깊은쇳덩이 3 | 전부. 가장 빠르다 |
| 돌 도끼 | 판자 2 + 돌 3 | 나무를 빠르게 |
| 쇠 도끼 | 판자 2 + 쇳덩이 3 | 나무를 더 빠르게 |
| 돌 삽 | 판자 2 + 돌 1 | 흙과 모래를 빠르게 |

- **맞는 도구가 없으면 부숴지지도 않는다.** 부숴는 지는데 아무것도 안 나오는
  쪽은 "고장 났나"로 읽힌다
- **도구는 닳지 않는다.** 고르는 재미는 등급에서 나오지 관리에서 나오지 않는다
- 곡괭이만 등급이 넷이다. 도끼와 삽은 빠르기만 바꾼다 — **깊이를 가르는 것은
  곡괭이 하나로 족하다**

## 만드는 자리 셋

**어디서 만들 수 있는가가 곧 테크트리의 마디다.** 재료만으로는 층이 생기지 않는다.

| 자리 | 어떻게 | 무엇을 |
|---|---|---|
| 손 | 언제나 | 판자 · 기본 도구 · 문 · 궤짝 · 밭 · 화로 · 부품 5종 · 등 |
| **화로** | **작동기가 때려야 한 번 돈다** | 굽는 것 전부 |
| 작업대 | 세 칸 안에 서서 | 쇳덩이가 드는 것 — 도구와 장치 |

- 화로는 신호 한 번에 한 번 굽는다. 굽는 시간은 없다.
  **되풀이의 간격이 곧 제련 속도다**
- 재료는 인벤토리에서 뺀다. 화로에 넣어 두는 칸은 없다. 넣어 두는 것은 궤짝이다
- 작업대는 사람이 쓴다, 회로가 아니라. 둘을 갈라 두어야 **"회로가 없으면 못 하는
  것"** 이 무엇인지 분명해진다

## 회로가 다루는 것 — 장치 열셋

**부품을 늘리지 않고 장치를 늘렸다.** §4.2 의 작동기 주석이 처음부터 그렇게
적어 두고 있었다 — *"이 설계 덕분에 나중에 블록을 추가해도 회로 부품은 늘지
않는다."*

|  | 전 | 지금 |
|---|---|---|
| 부품 | 5종 | **5종 그대로** |
| 감지기가 보는 것 | 5 | **8** (+밝기, +눌림, +손잡이) |
| 작동기가 다루는 것 | 4 | **8** (+화로, +발사대, +밀개, +놓개, +종) |
| §5 의 장치 | 5 | **17** |

### 새로 보는 것 둘

- **밝기** — 그 자리가 어두운가. 시간과 다르다. 시간은 섬 전체가 밤인가를 말하고
  밝기는 이 자리를 말한다. **땅속은 한낮에도 어둡다.** 굴을 파고 들어가면 저절로
  켜지는 등은 시간으로는 못 만든다
- **눌림** — 바로 그 칸을 무언가 밟고 있는가. 사람 감지기는 세 칸을 보고 사람만
  본다. 눌림은 한 칸을 보고 위협도 본다. **밟는 자리를 정확히 겨눌 수 있어야
  덫과 다리가 성립한다**

### 새로 다루는 것 다섯

| 블록 | 하는 일 | 만드는 곳 |
|---|---|---|
| 화로 | 한 번 굽는다 | 손 · 돌 8 |
| 밀개 | 마주 본 쪽으로 블록을 한 칸 민다 | 작업대 · 판자 3 · 쇳덩이 1 |
| 놓개 | 맞닿은 궤짝에서 하나를 꺼내 마주 본 빈 칸에 놓는다 | 작업대 · 판자 2 · 쇳덩이 2 |
| 종 | 소리를 낸다. 멀리서도 들린다 | 작업대 · 쇳덩이 3 |
| 발사대 | 마주 본 쪽 8칸 안의 첫 몸에게 **돌**을 쏜다 | 작업대 · 깊은쇳덩이 3 · 판자 2 |

- **밀개는 지형 블록만 민다.** 회로 부품과 궤짝은 못 민다 — 부품이 옮겨 다니면
  배선이 어디 붙었는지가 흔들린다. 한 번에 한 칸, 한 블록
- **종은 세계를 바꾸지 않는다.** 울렸다는 사실만 남기고 소리는 화면이 낸다.
  거리에 따라 작아지지 않는 유일한 소리다 — 섬 반대편에서 울려야 알림이 된다

### 부품이 말할 수 있는 문장이 늘었다

**부품은 다섯 종이지만 설정으로 갈린다**(§4.2). 그 가짓수가 곧 지을 수 있는
것의 넓이다. 장치를 하나씩 더하는 것보다 이쪽이 넓다.

| 부품 | 설정 | 전 | 지금 |
|---|---|---|---|
| 감지기 | 대상 × 거리 | 5 | **24** (대상 8 × 거리 3) |
| 작동기 | 방향 | **1** | **7** (여섯 쪽 + 전부) |
| 상자 | 모양 × 넣는 방식 | 3 | **6** (모양 3 × 덮어쓰기·더하기) |
| 갈림길 | 판정 | 6 | 6 |
| 되풀이 | 갈래 | 3 | 3 |
| | **합** | **18** | **46** |

세 군데가 비어 있었다.

- **작동기만 설정이 없었다.** 언제나 맞닿은 여섯 칸을 다 쳤다. 그래서 문 둘을
  나란히 달면 늘 함께 열리고, 밀개 셋을 붙이면 늘 함께 밀었다. 밀개 · 놓개 ·
  발사대가 마주 본 쪽을 갖는 물건이라 더 그렇다 — **무엇을 언제 움직일지는 회로가
  정하는데 어느 것을 움직일지는 정할 수 없었다**
- **감지기 거리가 3칸으로 고정이었다.** 덫은 밟은 칸만 봐야 하는데 옆 칸에도
  걸리고, 경보는 멀리 봐야 하는데 물리기 직전에 울렸다. 딱 앞 1 · 가까이 3 ·
  멀리 8 로 가른다
- **셈이 없었다.** 상자는 마지막 값만 들고, 갈림길은 견주기만 하고, 되풀이는
  도는 횟수만 셌다. **더하는 상자**를 두면 밟고 지나간 수를 세거나 몇 번째인지를
  아는 장치가 생긴다

### 사람이 회로를 켜는 길 — 손잡이

여태 신호를 내는 것은 감지기뿐이었고 감지기는 세계를 볼 뿐 사람 말을 듣지
않았다. **문을 손으로 열 수도, 조명을 손으로 끌 수도, 제련소를 손으로 멈출
수도 없었다.** 회로는 전부 저 혼자 도는 것이었다.

손잡이는 블록이다. 부품이 아니다. 사람이 젖히면 젖혀진 채로 머물고 맞닿은
감지기가 그것을 본다. **신호를 내는 것은 감지기뿐이라는 규칙은 깨지 않는다.**

눌림과 다르다 — 눌림은 밟는 동안만이고, 손잡이는 놓아 둔 대로 머문다.

## 발사대는 돌을 쏜다

오랫동안 작동기 표에 `발사대 | 발사` 한 줄로만 있었다. 무엇을 쏘는지도,
맞으면 어떻게 되는지도, 사거리도 탄도 적혀 있지 않았다.

| | |
|---|---|
| 탄 | 돌 1개 (쟁이는 한도 16발) |
| 사거리 | 마주 본 쪽 8칸 |
| 위협에게 | 1 — **세 번** 맞으면 사라진다 |
| 사람에게 | 2 — 위협에게 닿았을 때와 같다 |
| 날아가는 개체 | **없다.** 직선 위 첫 몸 |

- **탄을 새로 만들지 않았다.** 돌은 12817칸이 있고 늘 남았다.
  남는 자원에 소비처를 주는 편이 새 자원을 하나 더 만드는 것보다 낫다
- **개체를 만들지 않는다.** 하나 더 두면 상태 해시 · 저장 · 재생에 전부 얽힌다.
  §6 은 전투 시스템을 제외한다 — 발사대는 전투가 아니라 회로의 출력이다
- **세 발이어야** 되풀이를 쓸 이유가 생긴다. 한 방이면 발사대 하나로 밤이 끝난다
- **앞에 누가 있는지 묻지 않는다.** 사람도 맞는다. 어디에 놓을지 생각하게 된다
- **탄은 놓개가 채운다.** 발사대는 스스로 궤짝을 뒤지지 않는다

```
쏘는 회로    감지기(위협) → 갈림길(거리) → 되풀이 → 작동기 → 발사대
채우는 회로  감지기(물건) → 작동기 → 놓개 → 궤짝의 돌이 발사대로
```

열세 장치 가운데 **부품이 서로를 가장 많이 필요로 하는 자리다.**

## 첫날 예산 — 나무 한 그루로 자동문까지

판자가 나무 하나에 넷이 나오므로 첫날이 오히려 가벼워졌다.
전에는 나무 7이 들었다.

| 순서 | 쓰는 것 | 남는 판자 |
|---|---|---|
| 나무 한 그루를 벤다 (3칸) | — | — |
| 판자로 켠다 | 나무 3 | **12** |
| 나무 곡괭이 | 판자 3 | 9 |
| 돌을 캔다 | — | 9 |
| 돌 곡괭이 | 판자 2 + 돌 3 | 7 |
| 광석을 캔다 | — | 7 |
| 감지기 | 광석 2 + 판자 1 | 6 |
| 작동기 | 광석 1 + 판자 2 | 4 |
| 문 | 판자 4 | **0** |

**나무 3 · 돌 3 · 광석 3 — 한 그루가 정확히 떨어진다.**

그다음 두 걸음:

| 만드는 것 | 드는 것 |
|---|---|
| 화로 | 돌 8 |
| 자동 제련소 (감지기 + 되풀이 + 작동기 + 화로) | 광석 6 · 나무 1 · 돌 8 |

**자동문과 제련소가 같은 부품 두 개로 시작한다.** 둘째 날 회로를 만들 이유가
하나에서 둘이 된다.

## 왜 다시 설계했나

전에는 **두 단짜리 평면**이었다. 손으로 얻는 다섯 가지가 곧바로 물건이 되고
거기서 끝났다. 캐면 나오고 나오면 만들어진다. **어제 못 하던 것을 오늘 하게
되는 순간이 없었다.**

| 전에 | 지금 |
|---|---|
| 파낸 돌 12817개가 어느 제작법에도 들지 않았다 | 돌 도구 셋 · 화로 · 벽돌 · **발사대 탄** |
| 작물은 먹는 것 말고 쓰임이 없었다 | 구운 작물. 포만도 4 → **8** |
| 광석이 첫날에도 마지막 날에도 같은 광석이었다 | 광물 다섯 종이 **깊이로 갈린다** |
| 도구가 없어 첫 시간과 열 번째 시간의 손이 똑같았다 | 곡괭이 네 등급이 **캘 수 있는 것을 가른다** |
| 트리가 두 단뿐이었다 | **여섯 단.** 임계 경로 열다섯 마디 |
| 발사대가 스펙에만 있었다 | **트리의 마지막 칸.** §5 자동 방어가 열린다 |
| 발사대가 무엇을 쏘는지 아무 데도 없었다 | **돌.** 사거리 8칸, 위협 체력 3 |
| 회로로 지을 것이 다섯뿐이었다 | **열일곱.** 부품은 다섯 그대로 두고 다룰 것을 늘렸다 |
| 작동기에 설정이 없어 늘 여섯 칸을 다 쳤다 | **방향 7가지.** 한 짝만 여는 문이 가능해진다 |
| 감지기 거리가 3칸 고정이었다 | **딱 앞 1 · 가까이 3 · 멀리 8** |
| 셈이 없었다 | **더하는 상자.** 밟고 지나간 수를 센다 |
| 사람이 회로를 켤 방법이 없었다 | **손잡이.** 손 스위치 문 · 손으로 켜는 제련소 |

### 지킨 것 둘

- **부품은 다섯 종 그대로다.** §4.2 와 §4.4 는 손대지 않았다.
  §6 의 *"부품을 늘리기 전에 수위를 먼저 조정한다"* 를 지킨다
- **첫 자동문은 여전히 둘째 날에 닿는다.** §6 의 완료 판정 기준이 거기 걸려 있다

## 아직 정하지 않은 것

- **모래를 어디에 깔 것인가.** 물가라고만 정했다. 해안 띠(`SHORE_BAND` 6)의
  윗면을 모래로 두는 것이 자연스러운데, §3.1 의 "물가는 고르게 한 높이로 눕는다"와
  함께 봐야 한다
- **밝기 감지기가 "어둡다"를 어떤 수로 판정하는가.** 지금 등의 밝기는 표현
  레이어(`lamp_lights.gd`)가 계산한다. 시뮬레이션이 그것을 읽으면 §2 의 의존
  방향이 뒤집힌다. **밝기를 시뮬레이션 쪽으로 옮겨야 한다**
- **맞는 도구가 없을 때 무엇을 알리는가.** §1 은 원인을 말하지 말라고 하고,
  동시에 아무 일도 안 일어나는 것이 가장 나쁘다고 한다. 이미 있는 둔한
  소리 하나(`balk`)로 충분한지
- **화로가 무엇을 굽는지 어떻게 고르는가.** 지금 제작법 고르기(R)와 같은 길인지,
  화로마다 따로 정해 두는지. 후자면 놓인 화로의 설정이 밖에서 보여야 한다
  (§4.2 "놓인 부품을 읽는 것")
- **테스트가 꽤 늘어난다.** §7 은 새 부품마다 유닛 테스트와 결정론 회귀 테스트를
  함께 두라고 한다. 32개를 하나씩 쓰기보다 표를 돌며 검사하는 쪽이 낫다
