# 아이템 테크트리

**여섯 단이다.** 맨손에서 시작해 발사대에서 끝난다.

원본은 `docs/spec.md` §3.1 · §3.6 · §4.2 · §4.3 · §5 다. 여기 적힌 것은 그것을
한 장으로 편 것이고, 어긋나면 스펙이 옳다.

> **아직 구현되지 않았다.** 지금 코드에 있는 것은 자원 3종과 제작법 9개다.
> 이 문서는 그것을 무엇으로 바꿀지 적은 설계다.

---

## 왜 다시 설계했나

전에는 **두 단짜리 평면**이었다. 손으로 얻는 다섯 가지가 곧바로 물건이 되고
거기서 끝났다. 캐면 나오고 나오면 만들어진다. 고를 것이 없고, 어제 못 하던
것을 오늘 하게 되는 순간이 없다.

- 파낸 돌 12817개가 어느 제작법에도 들지 않았다
- 작물은 먹는 것 말고 쓰임이 없었다
- 광석은 첫날에도 마지막 날에도 같은 광석이었다. **깊이 내려갈 이유가 없었다**
- 도구가 없어 첫 시간과 열 번째 시간의 손이 똑같았다

---

## 네 가지 원칙

### 1. 가공은 회로가 돌린다

**이것이 중심이다.** 굽는 일은 손으로 못 한다. 화로는 작동기가 때려야 한 번 돈다.

```
되풀이 ──→ 작동기 ──→ 화로 = 자동 제련소
```

마인크래프트의 화로는 연료만 있으면 혼자 돈다. 아스트로니어의 모듈은 전력을
요구한다. 여기서 요구하는 것은 **회로**다. 그래서 테크트리가 코어 시스템과
다투지 않고 **그것을 쓸 이유**가 된다. 트리를 올라가려면 회로를 지어야 하고,
회로를 지으려면 트리를 올라가야 한다.

### 2. 첫 자동문은 여전히 둘째 날에 닿는다

스펙 §6 의 완료 판정 기준이 거기 걸려 있다 — *"첫날 밤을 손으로 버티고,
둘째 날 회로를 만들고 싶어지는가."* **깊이는 자동문 위에 쌓지, 그 앞에 놓지
않는다.** 뒤의 "첫날 예산"이 그것을 수로 보인다.

### 3. 부품은 다섯 종 그대로다

늘어나는 것은 재료 · 도구 · 작업 블록이다. §4.2 는 손대지 않는다.
§6 의 *"부품을 늘리기 전에 수위를 먼저 조정한다"* 를 지킨다.

### 4. 깊이는 세로에서 얻는다

세계가 z=24 이고 지하가 비어 있다. 광물 등급을 깊이로 가른다.
좋은 것은 아래에 있고, 아래로 갈수록 도구가 있어야 한다.

## 여섯 단

```
0단  맨손                나무 · 흙 · 모래 · 작물
      │
      ├─ 판자 (나무 1 → 4)
      │
1단   └─ 나무 곡괭이 (판자 3)
      ═══════════════════════════ 나무 곡괭이가 있어야 돌을 캔다
2단  돌                  돌 곡괭이 · 돌 도끼 · 돌 삽
                         화로 · 문 · 궤짝 · 밭
      ═══════════════════════════ 돌 곡괭이가 있어야 광석·불씨돌을 캔다
3단  광석 · 불씨돌        감지기 · 작동기 · 되풀이 · 상자 · 갈림길 · 등
      │                        └─ 여기서 자동문이 선다  ← §6 판정 지점
      ═══════════════════════════ 작동기가 화로를 때려야 굽는다
4단  화로에서             쇳덩이 · 벽돌 · 유리 · 숯 · 구운 작물
      ═══════════════════════════ 쇳덩이가 있어야 작업대가 선다
5단  작업대에서           작업대 · 쇠 곡괭이 · 쇠 도끼 · 튼튼한 문
      ═══════════════════════════ 쇠 곡괭이가 있어야 깊은광·빛돌을 캔다
6단  깊은광 · 빛돌        깊은쇳덩이 · 깊은쇠 곡괭이 · 밝은 등
                         발사대 ──→ 자동 방어 (§5 의 마지막 장치)
```

**임계 경로 열다섯 마디**

```
나무 → 판자 → 나무 곡괭이 → 돌 → 돌 곡괭이 → 광석 → 작동기 → 회로
  → 화로 → 쇳덩이 → 작업대 → 쇠 곡괭이 → 깊은광 → 깊은쇳덩이 → 발사대
```

## 자원 — 깊이가 등급이다

| 자원 | 어디에 | 맨손으로 | 쓰임 |
|---|---|---|---|
| 나무 | 지표의 나무 | 얻는다 | 판자 |
| 흙 | 지표에서 두 층 | 얻는다 | 밭, 메우기 |
| 모래 | 물가 | 얻는다 | 유리 |
| 작물 | 야생 14곳, 밭 | 얻는다 | 식량 |
| 돌 | 흙 아래 전부 | **못 얻는다** | 화로, 벽돌, 도구 |
| 광석 | 자원지 3곳, z ≤ 6 | **못 얻는다** | 부품, 쇳덩이 |
| 불씨돌 | z ≤ 5 | **못 얻는다** | 굽는 데 드는 것 |
| 깊은광 | z ≤ 3 | **못 얻는다** | 깊은쇳덩이 |
| 빛돌 | z ≤ 2 | **못 얻는다** | 밝은 등 |

한 층을 다 캐면 더 내려갈 까닭이 남아 있어야 한다. 전에는 광맥 하나뿐이라
한 번 내려가면 그것으로 끝이었다.

## 도구 — 무엇을 캘 수 있는지를 가른다

| 도구 | 드는 것 | 캘 수 있는 것 |
|---|---|---|
| 맨손 | — | 나무 · 흙 · 모래 · 작물 |
| 나무 곡괭이 | 판자 3 | + 돌 |
| 돌 곡괭이 | 판자 2 + 돌 3 | + 광석 · 불씨돌 |
| 쇠 곡괭이 | 판자 2 + 쇳덩이 3 | + 깊은광 · 빛돌 |
| 깊은쇠 곡괭이 | 판자 2 + 깊은쇳덩이 3 | 전부. 가장 빠르다 |
| 돌 도끼 | 판자 2 + 돌 3 | 나무를 빠르게 |
| 쇠 도끼 | 판자 2 + 쇳덩이 3 | 나무를 더 빠르게 |
| 돌 삽 | 판자 2 + 돌 1 | 흙과 모래를 빠르게 |

- **맞는 도구가 없으면 부숴지지도 않는다.** 부숴는 지는데 아무것도 안 나오는
  쪽은 "고장 났나"로 읽힌다
- **도구는 닳지 않는다.** 고르는 재미는 등급에서 나오지 관리에서 나오지 않는다

## 만드는 자리 셋

**어디서 만들 수 있는가가 곧 테크트리의 마디다.** 재료만으로는 층이 생기지 않는다.

| 자리 | 어떻게 | 무엇을 |
|---|---|---|
| 손 | 언제나 | 판자 · 기본 도구 · 문 · 궤짝 · 밭 · 화로 · 부품 5종 · 등 |
| **화로** | **작동기가 때려야 한 번 돈다** | 굽는 것 전부 |
| 작업대 | 세 칸 안에 서서 | 쇳덩이가 드는 것 |

- 화로는 신호 한 번에 한 번 굽는다. 굽는 시간은 없다. **되풀이의 간격이 곧
  제련 속도다**
- 재료는 인벤토리에서 뺀다. 화로에 넣어 두는 칸은 없다. 넣어 두는 것은 궤짝이다
- 작업대는 사람이 쓴다. 회로가 아니라. 둘을 갈라 두어야 "회로가 없으면 못 하는
  것"이 무엇인지가 분명해진다

## 첫날 예산 — 나무 한 그루로 자동문까지

판자가 나무 하나에 넷이 나오므로 첫날이 오히려 가벼워졌다.
전에는 나무 7이 들었다.

| 순서 | 쓰는 것 | 남는 판자 |
|---|---|---|
| 나무 한 그루를 벤다 (3칸) | — | — |
| 판자로 켠다 | 나무 3 | **12** |
| 나무 곡괭이 | 판자 3 | 9 |
| 돌을 캔다 | — | 9 |
| 돌 곡괭이 | 판자 2 + 돌 3 | 7 |
| 광석을 캔다 | — | 7 |
| 감지기 | 광석 2 + 판자 1 | 6 |
| 작동기 | 광석 1 + 판자 2 | 4 |
| 문 | 판자 4 | **0** |

**나무 3 · 돌 3 · 광석 3 — 한 그루가 정확히 떨어진다.**
자동문이 서면 §6 검증 순서 1번이다.

그다음 두 걸음:

| 만드는 것 | 드는 것 |
|---|---|
| 화로 | 돌 8 |
| 자동 제련소 (감지기 + 되풀이 + 작동기 + 화로) | 광석 6 · 나무 1 · 돌 8 |

**자동문과 제련소가 같은 부품 두 개로 시작한다.** 둘째 날 회로를 만들 이유가
하나에서 둘이 된다.

## 무엇이 풀렸나

전 판에서 적어 두었던 다섯 가지다.

| 전에 | 지금 |
|---|---|
| 돌 12817개에 쓸 곳이 없다 | 화로 · 벽돌 · 도구 셋. **첫 곡괭이부터 든다** |
| 작물이 제작에 참여하지 않는다 | 구운 작물. 포만도 4 → 8 |
| 트리가 두 단뿐이다 | **여섯 단.** 임계 경로 열다섯 마디 |
| 발사대가 스펙에만 있다 | **트리의 마지막 칸.** §5 자동 방어가 열린다 |
| 자원지 왕복이 6초다 | 그대로다. 다만 이제 자원지가 광물 다섯 중 하나일 뿐이고, **깊이가 새 거리**다 |

## 아직 정하지 않은 것

- **모래를 어디에 깔 것인가.** 물가라고만 정했다. 해안 띠(`SHORE_BAND` 6)의
  윗면을 모래로 두는 것이 자연스러운데, 그러면 §3.1 의 "물가는 고르게 한
  높이로 눕는다"와 함께 봐야 한다
- **도구를 손에 든다는 것이 화면에서 어떻게 보이는가.** 핫바 칸을 고르는 것과
  같은 자리인지, 따로 두는지
- **맞는 도구가 없을 때의 알림.** §1 은 원인을 말하지 말라고 하고, 동시에
  아무 일도 안 일어나는 것이 가장 나쁘다고 한다. 둔한 소리 하나로 충분한지
- **화로가 무엇을 굽는지 어떻게 고르는가.** 지금 제작법 고르기(R)와 같은 길인지
- 27개가 스펙 §7 의 "새 부품 추가 시 유닛 테스트와 결정론 회귀 테스트를 함께
  추가"를 그대로 받으면 테스트가 꽤 늘어난다. 묶어서 도는 표 기반 테스트가 낫다
