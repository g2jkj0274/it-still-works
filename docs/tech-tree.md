# 아이템 테크트리

**여섯 단이다.** 맨손에서 시작해 발사대에서 끝난다.
단마다 세계에서 할 수 있는 일이 하나씩 늘어난다 —
먹는다 → 판다 → **자동이 된다** → 재료를 만든다 → 짓는다 → 지킨다.

|  | 수 |
|---|---|
| 자원 | 9종 |
| 도구 | 8종 |
| 제작법 | 35개 |
| 만드는 자리 | 3곳 (손 · 화로 · 작업대) |
| 회로 부품 | **5종 — 그대로** |
| 감지기가 보는 것 | 8 |
| 작동기가 다루는 것 | 8 |
| 부품 설정 가짓수 | **46** |
| 지을 수 있는 장치 | 17 |

원본은 `docs/spec.md` §3.1 · §3.6 · §4.2 · §4.3 · §5 다. 어긋나면 스펙이 옳다.

> **0~2단은 구현되었다. 3단 위는 아직 설계다.**
>
> | | 설계 | 구현 |
> |---|---|---|
> | 제작법 | 35 | **15** |
> | 자원 | 9종 | 7종 (깊은광 · 빛돌 없음) |
> | 도구 | 8종 | 4종 (쇠 · 깊은쇠 없음) |
> | 만드는 자리 | 손 · 화로 · 작업대 | **손만** |
> | 회로 부품 | 5종 | 5종 (예전부터 있었다) |
>
> 아래 표에서 **✓** 는 지금 게임에서 되는 것이고, 표시가 없으면 설계뿐이다.
> **트리는 지금 3단에서 멈춘다** — 화로가 없어 쇳덩이가 나오지 않고,
> 그래서 쇠 곡괭이도 깊은 것들도 닿지 않는다.

## 여섯 단 — 닿으면 무엇이 달라지는가

### 0단 · 맨손 — **먹고 버틴다**

| | |
|---|---|
| 캔다 | 나무 · 흙 · 모래 · 작물 |
| 만든다 | 판자 |
| **할 수 있게 된다** | 배를 채운다. 흙과 나무를 쌓아 벽을 세운다 |
| 아직 못 한다 | **돌을 캘 수 없다.** 아무것도 자동이 아니다 |

야생 작물 열넷이 첫날의 시계다. 다시 나지 않는다.
배는 4분에 비고 5분 40초에 쓰러지는데 첫 밤은 7분에 온다.

**관문 →** 판자 3으로 **나무 곡괭이**

### 1단 · 판자 — **손이 도구를 갖는다**

나무 하나가 판자 넷이 된다. 이 환율이 첫날 예산을 세운다.

**판자는 제작법 35개 가운데 22개에 든다.** 도구도 부품도 장치도 전부 판자를
거친다. 나무가 사실상 모든 것의 뿌리다.

**관문 →** 나무 곡괭이가 **돌**을 연다

### 2단 · 돌 — **땅속이 열린다**

| | |
|---|---|
| 캔다 | 돌 |
| 만든다 | 돌 곡괭이 · 돌 도끼 · 돌 삽 · 화로 · 문 · 궤짝 · 밭 |
| **할 수 있게 된다** | 파고 내려간다. 문을 달고, 넣어 둘 곳을 갖고, 밭을 놓는다 |
| 아직 못 한다 | **화로를 세울 수는 있지만 돌릴 수는 없다** |

화로가 여기서 만들어지는데 손으로는 돌아가지 않는다.
**이 한 칸이 회로를 만들 이유가 된다.**

**관문 →** 돌 곡괭이가 **광석 · 불씨돌**을 연다

### 3단 · 회로 — **세계가 스스로 움직인다**

| | |
|---|---|
| 캔다 | 광석 · 불씨돌 |
| 만든다 | 감지기 · 작동기 · 되풀이 · 상자 · 갈림길 · 등 |
| **할 수 있게 된다** | **자동문 · 자동 조명 · 자동 농장.** 사람이 없어도 도는 것이 처음 생긴다. 등을 들고 더 깊이 내려간다 |

스펙 §6 검증 순서 1번이 여기다 — *"조작감이 재밌는가."*
**사람이 직접 판정하는 자리이고, 부품을 늘리기 전에 여기부터 봐야 한다.**

**관문 →** **작동기가 화로를 때린다**

### 4단 · 화로 — **재료가 재료를 낳는다**

| | |
|---|---|
| 굽는다 | 쇳덩이 · 깊은쇳덩이 · 벽돌 · 유리 · 숯 · 구운 작물 |
| **할 수 있게 된다** | **처음으로 캐지 않고 얻는다.** 여태 손에 든 것은 전부 땅에서 나온 것이었다 |

- 구운 작물이 포만도를 8 채운다. 날것은 4다 — 밥걱정이 준다
- 숯이 불씨돌을 대신한다. 나무 둘에 하나, 손해 보는 환율이다.
  땅속에 안 가고도 조금은 돌게 하되 내려가는 편이 늘 낫게 두었다
- **회로 없이는 이 단을 지날 수 없다.** 트리 전체의 허리다

**관문 →** **쇳덩이**가 작업대를 연다

### 5단 · 작업대 — **회로가 손을 갖는다**

| | |
|---|---|
| 만든다 | 작업대 · 쇠 곡괭이 · 쇠 도끼 · 튼튼한 문 · 밀개 · 놓개 · 종 |
| **할 수 있게 된다** | **회로가 짓고 옮기고 알린다** |

3단의 회로는 문을 여닫고 밭을 거두는 데 그쳤다. 여기서 회로가 **블록을 밀고
놓는다.** 덫문 · 자동 다리 · 자동 벽 · 경보가 이 단에서 선다.
튼튼한 문으로 밤에 회로를 지킨다.

**관문 →** **쇠 곡괭이**가 깊은광 · 빛돌을 연다

### 6단 · 깊은 곳 — **밤이 스스로 지켜진다**

| | |
|---|---|
| 캔다 | 깊은광 · 빛돌 |
| 만든다 | 깊은쇳덩이 · 깊은쇠 곡괭이 · 밝은 등 · 발사대 |
| **할 수 있게 된다** | **자동 방어.** §5 의 다섯 장치가 모두 선다 |

사람이 자는 동안에도 섬이 밤을 넘긴다.
밝은 등으로 가장 깊은 곳까지 밝아진다.

### 임계 경로 — 열다섯 마디

```
나무 → 판자 → 나무 곡괭이 → 돌 → 돌 곡괭이 → 광석 → 작동기 → 회로
  → 화로 → 쇳덩이 → 작업대 → 쇠 곡괭이 → 깊은광 → 깊은쇳덩이 → 발사대
```

### 지금 섬은 이렇게 되어 있다

위 표는 **넷으로 가른 뒤**의 목표다. 지금은 광맥을 **둘로만** 가른다 —
깊은광과 빛돌이 아직 없기 때문이다. 시드 고정 섬을 세어 보면 이렇다.

| 광물 | 실제 띠 | 칸 수 | 깊이별 |
|---|---|---|---|
| 불씨돌 | z3~6 | 846 | z6:123 · z5:92 · z4:213 · z3:418 |
| 광석 (지하) | z1~2 | 847 | z2:401 · z1:446 |
| 광석 (지상 자원지) | 지표 | 69 | 세 곳, 곳당 23 |

- **광석이 목표(z2~6)보다 깊다.** 광맥을 z3 에서 자르고 그 위를 전부 불씨돌로
  주었기 때문이다. 넷으로 가를 때 광석이 다시 올라온다
- 그래도 **첫 회로는 막히지 않는다.** 지상 자원지 69칸이 열다섯 걸음 밖에
  있고, 첫 굴(z2~6)의 바닥 벽에도 광석이 드러난다
- **"깊을수록 총량이 적다"는 아직 걸리지 않는다.** 그 규칙은 얕은 것과 깊은
  것의 총량을 벌리라는 말인데, 지금 둘은 846 대 847 로 거의 같다.
  깊은광(목표 120)과 빛돌(목표 40)이 들어올 때 비로소 걸린다.
  띠 **안에서** 깊을수록 잘 드는 것은 설계대로다

### 가운데를 지나는 것 둘

제작법 35개에서 재료가 몇 번 쓰이는지를 세면 줄기가 보인다.

| 재료 | 드는 제작법 |
|---|---|
| **판자** | **22** |
| 광석 | 7 |
| **쇳덩이** | **7** |
| 불씨돌 | 6 |
| 돌 | 5 |

- **판자**는 도구 · 부품 · 장치를 전부 거친다. 그래서 나무가 마르면 트리가 통째로
  선다. 섬에 나무가 30칸뿐이고 다시 나지 않는다는 것이 이 설계에서 가장 조이는 줄이다
- **쇳덩이**는 5단 전부의 뿌리다. 쇳덩이를 얻으려면 화로를 돌려야 하고, 화로를
  돌리려면 회로가 있어야 한다. **트리의 허리가 회로를 지나게 만든 것이 여기서 걸린다**

### 가장 좁은 줄기

모래 → 유리 → 밝은 등. 셋뿐이고 다른 데로 가지 않는다.
**모래는 밝은 등을 위해서만 존재한다.** 빛돌도 마찬가지다.

### 돌에 소비처가 생겼다

12817칸으로 가장 많이 나오는데 오래 쓸 곳이 없었다.
지금은 돌 도구 셋 · 화로 8 · 벽돌 · **발사대 탄**으로 나간다.
탄은 제작법이 아니라 쏠 때마다 하나씩 든다(§4.2).

## 도구 여덟 — 무엇을 캘 수 있는지를 가른다

| 도구 | 드는 것 | 캘 수 있는 것 | |
|---|---|---|---|
| 맨손 | — | 나무 · 흙 · 모래 · 작물 | ✓ |
| 나무 곡괭이 | 판자 3 | + 돌 · **불씨돌** | ✓ |
| 돌 곡괭이 | 판자 2 + 돌 3 | + 광석 | ✓ |
| 쇠 곡괭이 | 판자 2 + 쇳덩이 3 | + 깊은광 · 빛돌 | |
| 깊은쇠 곡괭이 | 판자 2 + 깊은쇳덩이 3 | 전부. 가장 빠르다 | |
| 돌 도끼 | 판자 2 + 돌 3 | 나무를 빠르게 | ✓ |
| 쇠 도끼 | 판자 2 + 쇳덩이 3 | 나무를 더 빠르게 | |
| 돌 삽 | 판자 2 + 돌 1 | 흙과 모래를 빠르게 | ✓ |

- **맞는 도구가 없으면 부숴지지도 않는다.** 부숴는 지는데 아무것도 안 나오는
  쪽은 "고장 났나"로 읽힌다
- **도구는 닳지 않는다.** 고르는 재미는 등급에서 나오지 관리에서 나오지 않는다
- 곡괭이만 등급이 넷이다. 도끼와 삽은 빠르기만 바꾼다 — **깊이를 가르는 것은
  곡괭이 하나로 족하다**

## 만드는 자리 셋

**어디서 만들 수 있는가가 곧 테크트리의 마디다.** 재료만으로는 층이 생기지 않는다.

| 자리 | 어떻게 | 무엇을 | |
|---|---|---|---|
| 손 | 언제나 | 판자 · 기본 도구 · 문 · 궤짝 · 밭 · 화로 · 부품 5종 · 등 | ✓ |
| **화로** | **작동기가 때려야 한 번 돈다** | 굽는 것 전부 | |
| 작업대 | 세 칸 안에 서서 | 쇳덩이가 드는 것 — 도구와 장치 | |

**지금 만드는 자리는 손뿐이다.** 화로가 없으므로 굽는 것이 하나도 없고,
그래서 쇳덩이가 나오지 않고, 그래서 작업대도 그 위도 서지 않는다.
**트리가 3단에서 멈추는 까닭이 이 한 칸이다.**

- 화로는 신호 한 번에 한 번 굽는다. 굽는 시간은 없다.
  **되풀이의 간격이 곧 제련 속도다**
- 재료는 인벤토리에서 뺀다. 화로에 넣어 두는 칸은 없다. 넣어 두는 것은 궤짝이다
- 작업대는 사람이 쓴다, 회로가 아니라. 둘을 갈라 두어야 **"회로가 없으면 못 하는
  것"** 이 무엇인지 분명해진다

## 회로가 다루는 것 — 장치 열셋

**부품을 늘리지 않고 장치를 늘렸다.** §4.2 의 작동기 주석이 처음부터 그렇게
적어 두고 있었다 — *"이 설계 덕분에 나중에 블록을 추가해도 회로 부품은 늘지
않는다."*

|  | 전 | 지금 |
|---|---|---|
| 부품 | 5종 | **5종 그대로** |
| 감지기가 보는 것 | 5 | **8** (+밝기, +눌림, +손잡이) |
| 작동기가 다루는 것 | 4 | **8** (+화로, +발사대, +밀개, +놓개, +종) |
| §5 의 장치 | 5 | **17** |

### 새로 보는 것 둘

- **밝기** — 그 자리가 어두운가. 시간과 다르다. 시간은 섬 전체가 밤인가를 말하고
  밝기는 이 자리를 말한다. **땅속은 한낮에도 어둡다.** 굴을 파고 들어가면 저절로
  켜지는 등은 시간으로는 못 만든다
- **눌림** — 바로 그 칸을 무언가 밟고 있는가. 사람 감지기는 세 칸을 보고 사람만
  본다. 눌림은 한 칸을 보고 위협도 본다. **밟는 자리를 정확히 겨눌 수 있어야
  덫과 다리가 성립한다**

### 새로 다루는 것 다섯

| 블록 | 하는 일 | 만드는 곳 |
|---|---|---|
| 화로 | 한 번 굽는다 | 손 · 돌 8 |
| 밀개 | 마주 본 쪽으로 블록을 한 칸 민다 | 작업대 · 판자 3 · 쇳덩이 1 |
| 놓개 | 맞닿은 궤짝에서 하나를 꺼내 마주 본 빈 칸에 놓는다 | 작업대 · 판자 2 · 쇳덩이 2 |
| 종 | 소리를 낸다. 멀리서도 들린다 | 작업대 · 쇳덩이 3 |
| 발사대 | 마주 본 쪽 8칸 안의 첫 몸에게 **돌**을 쏜다 | 작업대 · 깊은쇳덩이 3 · 판자 2 |

- **밀개는 지형 블록만 민다.** 회로 부품과 궤짝은 못 민다 — 부품이 옮겨 다니면
  배선이 어디 붙었는지가 흔들린다. 한 번에 한 칸, 한 블록
- **종은 세계를 바꾸지 않는다.** 울렸다는 사실만 남기고 소리는 화면이 낸다.
  거리에 따라 작아지지 않는 유일한 소리다 — 섬 반대편에서 울려야 알림이 된다

### 부품이 말할 수 있는 문장이 늘었다

**부품은 다섯 종이지만 설정으로 갈린다**(§4.2). 그 가짓수가 곧 지을 수 있는
것의 넓이다. 장치를 하나씩 더하는 것보다 이쪽이 넓다.

| 부품 | 설정 | 전 | 지금 |
|---|---|---|---|
| 감지기 | 대상 × 거리 | 5 | **24** (대상 8 × 거리 3) |
| 작동기 | 방향 | **1** | **7** (여섯 쪽 + 전부) |
| 상자 | 모양 × 넣는 방식 | 3 | **6** (모양 3 × 덮어쓰기·더하기) |
| 갈림길 | 판정 | 6 | 6 |
| 되풀이 | 갈래 | 3 | 3 |
| | **합** | **18** | **46** |

세 군데가 비어 있었다.

- **작동기만 설정이 없었다.** 언제나 맞닿은 여섯 칸을 다 쳤다. 그래서 문 둘을
  나란히 달면 늘 함께 열리고, 밀개 셋을 붙이면 늘 함께 밀었다. 밀개 · 놓개 ·
  발사대가 마주 본 쪽을 갖는 물건이라 더 그렇다 — **무엇을 언제 움직일지는 회로가
  정하는데 어느 것을 움직일지는 정할 수 없었다**
- **감지기 거리가 3칸으로 고정이었다.** 덫은 밟은 칸만 봐야 하는데 옆 칸에도
  걸리고, 경보는 멀리 봐야 하는데 물리기 직전에 울렸다. 딱 앞 1 · 가까이 3 ·
  멀리 8 로 가른다
- **셈이 없었다.** 상자는 마지막 값만 들고, 갈림길은 견주기만 하고, 되풀이는
  도는 횟수만 셌다. **더하는 상자**를 두면 밟고 지나간 수를 세거나 몇 번째인지를
  아는 장치가 생긴다

### 사람이 회로를 켜는 길 — 손잡이

여태 신호를 내는 것은 감지기뿐이었고 감지기는 세계를 볼 뿐 사람 말을 듣지
않았다. **문을 손으로 열 수도, 조명을 손으로 끌 수도, 제련소를 손으로 멈출
수도 없었다.** 회로는 전부 저 혼자 도는 것이었다.

손잡이는 블록이다. 부품이 아니다. 사람이 젖히면 젖혀진 채로 머물고 맞닿은
감지기가 그것을 본다. **신호를 내는 것은 감지기뿐이라는 규칙은 깨지 않는다.**

눌림과 다르다 — 눌림은 밟는 동안만이고, 손잡이는 놓아 둔 대로 머문다.

### 지을 수 있는 것 열일곱

| 장치 | 구성 | 단 |
|---|---|---|
| 자동문 | 감지기(사람) → 작동기(문) | 3 |
| 자동 조명 | 감지기(시간) → 작동기(등) | 3 |
| 자동 농장 | 감지기(작물) → 되풀이 → 작동기(밭) | 3 |
| 자동 제련소 | 되풀이 → 작동기(화로) | 3 |
| 지하 등 | 감지기(밝기) → 작동기(등) | 3 |
| 곳간 지기 | 감지기(물건) → 갈림길(≥ 32) → 작동기(종) | 5 |
| 경보 | 감지기(위협) → 작동기(종) | 5 |
| 덫문 | 감지기(눌림) → 갈림길(위협인가) → 작동기(밀개) | 5 |

성립해야 하는 것들이고, 나머지는 사람이 발명한다.

## 발사대는 돌을 쏜다

오랫동안 작동기 표에 `발사대 | 발사` 한 줄로만 있었다. 무엇을 쏘는지도,
맞으면 어떻게 되는지도, 사거리도 탄도 적혀 있지 않았다.

| | |
|---|---|
| 탄 | 돌 1개 (쟁이는 한도 16발) |
| 사거리 | 마주 본 쪽 8칸 |
| 위협에게 | 1 — **세 번** 맞으면 사라진다 |
| 사람에게 | 2 — 위협에게 닿았을 때와 같다 |
| 날아가는 개체 | **없다.** 직선 위 첫 몸 |

- **탄을 새로 만들지 않았다.** 돌은 12817칸이 있고 늘 남았다.
  남는 자원에 소비처를 주는 편이 새 자원을 하나 더 만드는 것보다 낫다
- **개체를 만들지 않는다.** 하나 더 두면 상태 해시 · 저장 · 재생에 전부 얽힌다.
  §6 은 전투 시스템을 제외한다 — 발사대는 전투가 아니라 회로의 출력이다
- **세 발이어야** 되풀이를 쓸 이유가 생긴다. 한 방이면 발사대 하나로 밤이 끝난다
- **앞에 누가 있는지 묻지 않는다.** 사람도 맞는다. 어디에 놓을지 생각하게 된다
- **탄은 놓개가 채운다.** 발사대는 스스로 궤짝을 뒤지지 않는다

```
쏘는 회로    감지기(위협) → 갈림길(거리) → 되풀이 → 작동기 → 발사대
채우는 회로  감지기(물건) → 작동기 → 놓개 → 궤짝의 돌이 발사대로
```

열세 장치 가운데 **부품이 서로를 가장 많이 필요로 하는 자리다.**

## 첫날 예산 — 나무 한 그루로 자동문까지

판자가 나무 하나에 넷이 나오므로 첫날이 오히려 가벼워졌다.
전에는 나무 7이 들었다.

| 순서 | 쓰는 것 | 남는 판자 |
|---|---|---|
| 나무 한 그루를 벤다 (3칸) | — | — |
| 판자로 켠다 | 나무 3 | **12** |
| 나무 곡괭이 | 판자 3 | 9 |
| 돌을 캔다 | — | 9 |
| 돌 곡괭이 | 판자 2 + 돌 3 | 7 |
| 광석을 캔다 | — | 7 |
| 감지기 | 광석 2 + 판자 1 | 6 |
| 작동기 | 광석 1 + 판자 2 | 4 |
| 문 | 판자 4 | **0** |

**나무 3 · 돌 3 · 광석 3 — 한 그루가 정확히 떨어진다.**

그다음 두 걸음:

| 만드는 것 | 드는 것 |
|---|---|
| 화로 | 돌 8 |
| 자동 제련소 (감지기 + 되풀이 + 작동기 + 화로) | 광석 6 · 나무 1 · 돌 8 |

**자동문과 제련소가 같은 부품 두 개로 시작한다.** 둘째 날 회로를 만들 이유가
하나에서 둘이 된다.

## 왜 다시 설계했나

전에는 **두 단짜리 평면**이었다. 손으로 얻는 다섯 가지가 곧바로 물건이 되고
거기서 끝났다. 캐면 나오고 나오면 만들어진다. **어제 못 하던 것을 오늘 하게
되는 순간이 없었다.**

| 전에 | 지금 |
|---|---|
| 파낸 돌 12817개가 어느 제작법에도 들지 않았다 | 돌 도구 셋 · 화로 · 벽돌 · **발사대 탄** |
| 작물은 먹는 것 말고 쓰임이 없었다 | 구운 작물. 포만도 4 → **8** |
| 광석이 첫날에도 마지막 날에도 같은 광석이었다 | 광물 다섯 종이 **깊이로 갈린다** |
| 도구가 없어 첫 시간과 열 번째 시간의 손이 똑같았다 | 곡괭이 네 등급이 **캘 수 있는 것을 가른다** |
| 트리가 두 단뿐이었다 | **여섯 단.** 임계 경로 열다섯 마디 |
| 발사대가 스펙에만 있었다 | **트리의 마지막 칸.** §5 자동 방어가 열린다 |
| 발사대가 무엇을 쏘는지 아무 데도 없었다 | **돌.** 사거리 8칸, 위협 체력 3 |
| 회로로 지을 것이 다섯뿐이었다 | **열일곱.** 부품은 다섯 그대로 두고 다룰 것을 늘렸다 |
| 작동기에 설정이 없어 늘 여섯 칸을 다 쳤다 | **방향 7가지.** 한 짝만 여는 문이 가능해진다 |
| 감지기 거리가 3칸 고정이었다 | **딱 앞 1 · 가까이 3 · 멀리 8** |
| 셈이 없었다 | **더하는 상자.** 밟고 지나간 수를 센다 |
| 사람이 회로를 켤 방법이 없었다 | **손잡이.** 손 스위치 문 · 손으로 켜는 제련소 |

### 지킨 것 둘

- **부품은 다섯 종 그대로다.** §4.2 와 §4.4 는 손대지 않았다.
  §6 의 *"부품을 늘리기 전에 수위를 먼저 조정한다"* 를 지킨다
- **첫 자동문은 여전히 둘째 날에 닿는다.** §6 의 완료 판정 기준이 거기 걸려 있다

## 아이템을 갈래별로 세어 보면

모두 **45**개다. 마인크래프트는 천 단위지만 그 수의 대부분이 건축 블록이라
날 것으로 견주는 것은 뜻이 없다. **어느 갈래가 비어 있는지**를 본다.

| 갈래 | 마인크래프트 | 우리 | |
|---|---|---|---|
| 원자재 | 많다 | 9 | 충분하다 |
| 가공재 | 많다 | 8 | 충분하다 |
| 회로 | 12가지쯤 | 부품 5 + 장치 8 | **우리가 더 깊다** |
| 블록 · 장치 | 많다 | 13 | 충분하다 |
| 도구 | 9갈래 × 5등급 | 3갈래 × 2~4등급 | 얇지만 뜻이 있다 |
| **놓아서 짓는 것** | **수백** | **5 → 10** | **가장 빈 곳. 늘렸다** |
| 음식 | 20가지쯤 | 2 | **못 늘린다** |
| 방어구 | 20 | 0 | **안 늘린다** |

### 첫 굴에 빛이 없었다

세다가 발견한 것이다. 등은 **광석**이 들고 광석은 **돌 곡괭이**가 있어야 캐는데,
파고 내려가기 시작하는 것은 **나무 곡괭이**일 때다. 어두운 곳에 위협이 나게
된 지금(§3.8) **빛 없는 첫 굴은 그냥 죽는 길이다.**

마인크래프트에서 횃불의 재료인 석탄이 나무 곡괭이로 캐지는 자리가 여기다.

> **불씨돌을 나무 곡괭이로 캔다.** 그리고 **관솔불**(판자 1 + 불씨돌 1 → 4개)을
> 손으로 만든다. 놓으면 작게 밝히고 **작동기가 여닫지 못한다** — 늘 켜져 있는
> 것이 등과 다른 점이고, 그래서 회로 없이도 굴을 밝힐 수 있다.

돌 곡괭이의 관문은 이제 광석 하나다. 마인크래프트에서 돌 곡괭이가 철만 여는
것과 같은 모양이다.

### 놓아서 짓는 것을 다섯에서 열로

마인크래프트의 아이템 다양성 대부분이 건축 블록이다. **우리 쪽에서 그것이 하는
일은 지은 회로를 감추고 꾸미는 것이다.** 배선과 부품 표시가 눈에 잘 띄게
그려지므로(§4.1) 가릴 것이 있어야 한다.

| | |
|---|---|
| 캔 것을 그대로 | 흙 · 돌 · 나무 · **모래** |
| 만든 것을 | **판자** · 벽돌 · **다듬은 돌** · 유리 · **빛벽돌** |
| 빛나는 것 | **관솔불** |

**형태가 다른 블록(계단 · 반블록)은 두지 않는다.** 한 칸이 한 블록이라는 격자
규칙과 이동 판정(§3.3)을 건드린다. 늘리는 것은 **빛깔과 무늬**까지다.

### 못 늘리는 것 둘

- **음식이 둘뿐이다** — 작물과 구운 작물. 새 먹거리를 만들려면 새 식재료가
  필요한데 우리에게 식재료는 작물 하나뿐이고, §6 이 몹 다양화를 제외하므로
  고기도 없다. **늘리려면 스펙의 제외 목록부터 바꿔야 한다**
- **방어구가 없다** — §6 이 전투 시스템을 제외한다. 우리 쪽 답은 몸에 걸치는
  것이 아니라 **튼튼한 문**이다. 사람이 강해지는 것이 아니라 지은 것이 버틴다

## 마인크래프트와 견주어

같은 모양의 트리인지, 어디가 다른지, 다른 것이 뜻이 있는 다름인지를 봤다.

| 무엇 | 마인크래프트 | 우리 | |
|---|---|---|---|
| 진행 축 | 나무 → 돌 → 철 → 다이아 → 네더 | 나무 → 돌 → 광석 → 쇳덩이 → 깊은광 | 같다 |
| 관문 | 곡괭이 등급이 캘 것을 가른다 | 같다 | 같다 |
| 가공 | 화로 — 연료만 있으면 혼자 돈다 | 화로 — **회로가 돌린다** | **우리 쪽 특징** |
| 작업대 | 2단, 싸다 | 5단, 늦다 | 뜻이 있는 다름 |
| 도구 내구도 | 있다. 계속 다시 만든다 | 없다 | 뜻이 있는 다름 |
| 나무 | **묘목으로 다시 난다** | **다시 나지 않는다** | **✗ 고쳤다** |
| 깊이의 대가 | 어두운 곳에 몹이 난다 | **없다** | **✗ 고쳤다** |
| 광물 희소성 | 깊을수록 귀하고 **적다** | 깊을수록 **많다** | **✗ 고쳤다** |

### 고친 것 셋

**나무가 다시 나지 않았다.** 판자가 제작법 32개 가운데 21개에 드는데 섬에
나무가 30칸뿐이고 다시 나지 않는다. 마르면 도구도 부품도 장치도 더 만들 수
없고 트리 전체가 거기서 선다. 마인크래프트가 묘목을 둔 자리가 여기다.

> **흙 윗면 바로 위에 놓은 나무는 뿌리를 내린다.** 3분이면 세 칸으로 자란다.
> 나무 1 이 나무 3 이 된다. 다른 나무 위나 돌 위에 놓은 것은 그냥 블록이라
> 벽으로 쌓는 길은 막히지 않는다. 거두는 것은 **손**이다 — 밭처럼 작동기를
> 요구하면 "나무가 없으면 작동기를 못 만든다"로 고리가 물린다.

**깊이에 대가가 없었다.** 트리 전체가 깊이 축인데 낮에 파고 내려가는 데
아무 위험이 없다. 게다가 재어 보니 **위협 넷 중 둘쯤(44%)이 지표 아래
5~9칸, 굴 안에서 난다** — 자리를 고르는 것이 "그 기둥에서 설 수 있는 가장
낮은 칸"이기 때문이다. 사람에게 닿지도 못하고 밤이 조용해진다.

> **어두운 칸에서 난다. 시각이 아니라 밝기가 기준이다.** 지표는 밤에 어두우니
> 밤은 지금과 같이 오고, 땅속은 늘 어두우니 낮에도 굴에서 난다. 그리고
> **등이 밝힌 자리에서는 나지 않는다** — 지금 등은 보이게 하는 것뿐인데
> 여기서 진짜 쓸모가 생기고, 지하 등 회로가 필수가 된다.

**깊을수록 광물이 많았다.** 재어 보면 광맥이 z1 에 446칸, z6 에 123칸이다.
광물이 하나뿐일 때는 "깊을수록 흔하다"가 맞았지만 다섯으로 갈린 지금은
**제일 귀해야 할 빛돌이 제일 흔해진다.** 마인크래프트의 다이아가 값진 것은
깊어서가 아니라 **깊고 적어서**다.

| 광물 | 띠 | 섬 전체 목표 |
|---|---|---|
| 불씨돌 | z3~7 | 약 600 |
| 광석 | z2~6 | 약 600 |
| 깊은광 | z1~3 | 약 120 |
| 빛돌 | z1~2 | 약 40 |

> 한 광물은 **자기 띠 안에서는** 깊을수록 잘 든다. 다만 띠가 깊을수록 그 광물의
> 총량이 적다. 그래야 "더 내려간다"가 "더 많이 캔다"가 아니라 **"더 좋은 것을
> 조금 캔다"** 가 된다. 넷을 합쳐 1360칸이고 지금 광맥이 1693칸이니 광맥이
> 나는 빈도 자체는 건드리지 않는다.

### 고치지 않은 것 셋

- **작업대가 늦다.** 마인크래프트의 제작대는 2단이고 싸다. 우리 것은 5단이고
  쇳덩이가 든다. 이것은 의도다 — 우리 트리의 허리는 작업대가 아니라 **화로**이고,
  손으로 만드는 것에 마찰을 더하면 회로에 닿는 길이 멀어진다
- **도구가 닳지 않는다.** 마인크래프트는 내구도로 초반 자원을 계속 쓰게 만든다.
  우리는 **고르는 재미를 등급에 두고 관리에 두지 않기로** 했다(§3.6).
  나무가 다시 나게 된 지금 되살릴 수도 있지만, 그러면 벌목이 일이 된다
- **죽으면 절반이 사라진다.** 마인크래프트는 그 자리에 떨궈서 되찾으러 가게
  한다. 우리 쪽이 더 가혹하고 덜 재밌다. 다만 떨어진 것을 줍는 길이 아직
  없어서(§3.1) 지금은 바꿀 수 없다

## 아직 정하지 않은 것

- **모래를 어디에 깔 것인가.** 물가라고만 정했다. 해안 띠(`SHORE_BAND` 6)의
  윗면을 모래로 두는 것이 자연스러운데, §3.1 의 "물가는 고르게 한 높이로 눕는다"와
  함께 봐야 한다
- **밝기 감지기가 "어둡다"를 어떤 수로 판정하는가.** 지금 등의 밝기는 표현
  레이어(`lamp_lights.gd`)가 계산한다. 시뮬레이션이 그것을 읽으면 §2 의 의존
  방향이 뒤집힌다. **밝기를 시뮬레이션 쪽으로 옮겨야 한다**
- **맞는 도구가 없을 때 무엇을 알리는가.** §1 은 원인을 말하지 말라고 하고,
  동시에 아무 일도 안 일어나는 것이 가장 나쁘다고 한다. 이미 있는 둔한
  소리 하나(`balk`)로 충분한지
- **화로가 무엇을 굽는지 어떻게 고르는가.** 지금 제작법 고르기(R)와 같은 길인지,
  화로마다 따로 정해 두는지. 후자면 놓인 화로의 설정이 밖에서 보여야 한다
  (§4.2 "놓인 부품을 읽는 것")
- **땅속 위협이 쌓이지 않게 하는 상한.** 날이 밝아도 땅속의 것은 남는다고
  적었다. 섬 전체 여덟이라는 상한으로 충분한지, 아니면 오래된 것부터
  사라져야 하는지
- **나무가 자라는 데 3분.** 작물이 90초이므로 두 배다. 첫날에 벤 나무가
  둘째 날 아침에 돌아오는 정도인데 재어 보지 않은 추측이다
- **테스트가 꽤 늘어난다.** §7 은 새 부품마다 유닛 테스트와 결정론 회귀 테스트를
  함께 두라고 한다. 35개를 하나씩 쓰기보다 표를 돌며 검사하는 쪽이 낫다
